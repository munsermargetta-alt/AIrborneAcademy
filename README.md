# AIrborne Academy — sitio y herramientas

Sitio público de **AIrborne Academy** (https://airborneacademy.app) y la app web instalable de calculadoras de aviación.

- `index.html`, `estilos.css`, `privacidad.html`, `terminos.html`, `img/`: página principal y avisos legales.
- `app/`: app de herramientas (funciona sin internet).
  - `calc.js`: motor de cálculo (solo matemáticas, comentado).
  - `pruebas_calc.js`: pruebas automáticas — `node app/pruebas_calc.js`.
  - `app.js`, `app.css`, `index.html`: pantallas.
  - `esperas.html`: computador de esperas y acrónimos.
  - `sw.js`, `manifest.webmanifest`: instalación y modo sin internet.
- `CNAME`: dominio propio para GitHub Pages.

Herramienta de estudio: no sustituye al POH/AFM, a la planeación oficial ni a un instructor.
